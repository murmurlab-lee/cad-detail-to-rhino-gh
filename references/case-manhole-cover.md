# 案例：隐形铺装井盖（600×600 井口）

> 完整跑通过程的真实案例（用户已验收）。新任务照此模式推导自己的几何。
> 配套资产：`assets/manhole_body.cs`（C# 脚本体）、`assets/ghx_spec_example.json`（规格样例）。

## 输入

- 井盖详图.pdf：纯矢量 CAD 导出（文本读取为空），线宽极细 → pdf_to_png.py 150dpi + 阈值增强
- 4 张现场照片：完成面只见一圈约 18mm 金属边 + 8mm 缝隙 + 与周边铺装同材质盖面

## 疑问清单（用户确认结果）

| 问题 | 裁定 |
|---|---|
| 井口净空（图纸两处矛盾） | 600×600mm |
| 托盘深度 | 80mm（铺装20 + 砂浆25 + 钢网 + 底板） |
| 底板厚度（平面注 2mm vs 剖面注 10mm 的矛盾） | 以剖面为准：10mm 镀锌钢板 |
| 建模范围 | 井盖本体 + 混凝土井圈 + 周边一圈铺装（表达交接关系） |

## 关键设计决策：Z 形外框

图纸同时存在"70mm 法兰"和"18mm 可见边"，照片只见约 18mm 金属。
自洽解：**Z 形截面**——18mm 顶唇（与完成面平齐）→ 腹板下行 → 70mm 底法兰
**埋在周边砂浆层下**压在井圈上。教训：图纸标注矛盾时用剖面构造逻辑+照片证据求解，
并把推理写进假设说明。

## 参数体系（13 滑块）

井口净空400-1200=600 / 托盘深度60-120=80 / 缝隙2-20=8(1位小数) / 外框可见边10-40=18 /
外框板厚3-10=6 / 托盘壁厚5-15=10 / 底板厚2-15=10 / 肋网格数量2-8=5 / 肋厚3-10=6 /
肋高30-80=50 / 井圈壁厚80-150=100 / 井圈深度100-300=150 / 铺装厚度15-40=20

坐标推导（半宽，中心为 0；z=0 完成面，向下为负）：

```
OH=OPEN/2; X_WEB_OUT=OH+20; X_BAND_IN=X_WEB_OUT-FT; X_LEDGE_IN=X_BAND_IN-16
X_RIM_OUT=X_BAND_IN-GAP; X_WALL_OUT=X_RIM_OUT-26; X_PAV_IN=X_WALL_OUT-WT
X_LIP_OUT=X_BAND_IN+LIP; X_FRAME_OUT=X_WEB_OUT+RINGT; X_SURR_OUT=X_LIP_OUT+600
zLipB=-FT; zLedgeB=-FT-8; zWebB=-(PT+25); zFlgB=zWebB-FT; zRingB=zFlgB-RINGD
```

## 构件分解（10 图层 / 60 构件）

01 不锈钢外框(4环×4块) / 02 不锈钢托盘(翻边+壁) / 03 镀锌底板 / 04 钢网 /
05 砂浆(托盘内+周边) / 06 铺装(盖面+周边) / 07 加强肋(N×N=5×5 共10条) /
08 橡胶垫块(6) / 09 开启孔(4角凹槽) / 10 混凝土井圈

## 相交校验白名单（有意相交）

钢网×砂浆（嵌埋）、肋×肋（交叉）、开启孔×铺装（开槽）。其余相交清零后才交付。
